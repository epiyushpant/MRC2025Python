## 📚 Course Overview

This repository contains comprehensive materials for the Python Programming course taught in the 7th semester of the BICTE program at Mahendra Ratna Campus, Tahachal, Kathmandu. The course covers fundamental to advanced Python concepts with hands-on assignments and practical implementations.

## 🎯 Learning Objectives

By the end of this course, students will be able to:

- ✅ **Master Python Fundamentals**: Variables, data types, operators, and basic syntax
- ✅ **Implement Control Structures**: Conditional statements, loops, and program flow
- ✅ **Work with Data Structures**: Lists, tuples, sets, dictionaries, and their applications
- ✅ **Apply Object-Oriented Programming**: Classes, objects, inheritance, and encapsulation
- ✅ **Handle Functions & Exceptions**: Function definition, error handling, and file operations
- ✅ **Develop Database Applications**: SQLite integration and GUI development
- ✅ **Create Graphics Applications**: Basic computer graphics using Python libraries

## 📖 Course Units

### 🔰 Unit 1: Python Fundamentals
- Variables and data types
- Basic operators and expressions
- Input/output operations

### 🔄 Unit 2: Control Statements  
- Conditional statements (if, elif, else)
- Loops (for, while)
- Break and continue statements
- Nested control structures

### 📊 Unit 3: Data Structures
- Lists: creation, indexing, slicing, methods
- Tuples: immutable sequences
- Sets: unique elements and operations
- Dictionaries: key-value pairs and methods

### 🏛️ Unit 4: Object-Oriented Programming
- Classes and objects
- Attributes and methods
- Inheritance and polymorphism
- Encapsulation and abstraction

### ⚙️ Unit 5: Functions, Exceptions & Files
- Function definition and calling
- Parameters and return values
- Exception handling (try, except, finally)
- File input/output operations

### 💾 Unit 6: Database & GUI
- SQLite database operations
- GUI development with Tkinter
- Database-GUI integration
- Project development

## 🚀 Getting Started

### Prerequisites
- Python 3.8 or higher installed
- Jupyter Notebook or JupyterLab
- Basic understanding of programming concepts

### Installation & Setup

1. **Clone the repository**
   ```bash
   git clone <repository-url>
   cd Python_Course
   ```

2. **Create virtual environment**
   ```bash
   python -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate
   ```

3. **Install required packages**
   ```bash
   pip install jupyter matplotlib pillow sqlite3
   ```

4. **Launch Jupyter Notebook**
   ```bash
   jupyter notebook
   ```

## 📝 Assignment Guidelines

### 📋 How to Use This Repository

1. **Start with Unit 1**: Begin with `unit1_python_fundamentals.ipynb`
