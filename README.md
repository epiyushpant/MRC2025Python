Welcome to my comprehensive collection of **Python programming assignments** for BICTE 7th Semester! This repository contains chapter-wise Jupyter Notebook files designed for interactive learning and hands-on practice with Python programming concepts.

Each notebook is carefully structured with:
- 📝 Detailed explanations and theory
- 💻 Practical code examples  
- 🎯 Hands-on exercises and assignments

## 🚀 How to Use

### Prerequisites
- Python 3.7+ installed
- Jupyter Notebook or JupyterLab
- MySQL (for database chapters)

### Getting Started

1. **Clone the repository:**

   git clone https://github.com/epiyushpant/MRC2025Python.git
   && cd python-assignments
   

2. **Install required packages:**
   
   pip install -r requirements.txt
   

3. **Launch Jupyter Notebook:**
   
   jupyter notebook
   

4. **Navigate to desired chapter and start learning! 🎉**
